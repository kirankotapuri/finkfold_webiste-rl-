## 📌 Overview

**Finkfold Web Application** is the primary public-facing portal for the Finkfold platform. It hosts the product showcase, interactive landing pages for AI and automation solutions, and the **Finkfold Academy**—an educational hub providing guides, interactive tutorials, and resources for AI integrations and workflow automation.

## 🔗 Live Application Link

- **Finkfold Academy & Portal:** [https://finkfold-website.vercel.app/academy](https://finkfold-website.vercel.app/academy)

---

## ✨ Key Features

- **Academy Hub:** Educational modules, documentation, and resources for AI agents and workflow integration.
- **Interactive Lead Capture:** Conversion-optimized landing pages integrated directly with backend automated intake pipelines.
- **Responsive Modern UI:** Fully mobile-optimized layout built with Tailwind CSS and Next.js App Router.
- **Dynamic Content Delivery:** Fast static and server-rendered pages for optimal performance and SEO.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router / React)
- **Styling:** Tailwind CSS, Lucide React Icons
- **Backend Services:** Supabase (Database & Auth), n8n Automated Webhooks
- **Deployment:** Vercel
